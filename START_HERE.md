## 💻 TECHNICAL DETAILS

### Frontend
- **Technology**: HTML5 + CSS3 + Vanilla JavaScript
- **Features**: SPA (Single Page Application), no build required
- **Storage**: localStorage for JWT tokens and user data
- **API Communication**: Fetch API with async/await
- **Styling**: Modern CSS with variables, flexbox, grid
- **Responsive**: Mobile-first design approach

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB
- **Authentication**: JWT (jsonwebtoken)
- **Password**: Bcryptjs (10 rounds)
- **Upload**: Multer (PDF, DOC, DOCX)
- **CORS**: Enabled
- **Environment**: dotenv

### Database
- **MongoDB**: localhost:27017/job_portal
- **Collections**: users, jobs, applications
- **Relationships**: User → Job → Application (references)
